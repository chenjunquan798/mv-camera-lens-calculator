# 工业相机 & 镜头选型计算器

> Machine Vision Camera & Lens Selection Calculator

输入「最大视野」和「精度要求」，自动计算所需相机分辨率、推荐传感器型号、镜头焦距、解像力要求与景深，并提示线阵相机 / 远心镜头方案。

🔗 **在线使用（无需安装）**：https://chenjunquan798.github.io/mv-camera-lens-calculator/

---

## 功能

- **反算相机规格**：由精度要求（k=2~3 像素）→ 像素当量 → 所需最小分辨率（如 4000×3000 px）
- **推荐传感器**：内置 12 款常用工业面阵传感器（Sony IMX273/252/250/253/178/183/334/342/530、ON Semi PYTHON 系列），按"满足要求且成本最低"排序
- **推荐镜头**：标准焦距（4~200mm）、对应工作距离、镜头像素等级、奈奎斯特解像力要求（lp/mm）、靶面要求
- **景深校核**：`DOF ≈ 2·δ·F数·(1+β)/β²`，支持输入光圈
- **风险提示**：
  - 分辨率超过面阵极限 → 线阵相机建议（含像素档位、所需线频）
  - 被测面有高度差 → 离焦与倍率误差校核，提示远心镜头
  - 运动目标 → 曝光时间上限（控制运动模糊 ≤ ½ 像素）
- **输出报告**：一键复制文字报告 / 打印成 PDF，可直接发客户

## 使用方法

1. 下载 `index.html`，双击用浏览器打开（离线可用，无任何依赖）
2. 填写必填项：**最大视野 宽 × 高**、**精度要求**
3. 选填：工作距离范围、被测面高度差、光圈 F 数、运动速度、自定义传感器
4. 点「计算选型」，查看推荐方案与提示

## 计算公式

| 步骤 | 公式 | 说明 |
|---|---|---|
| 像素当量 | `δ = 精度要求 ÷ k` | k=2~3，一个特征至少占 k 个像素 |
| 所需分辨率 | `N = 视野 ÷ δ` | 双向分别计算，向上取整 |
| 成像倍率 | `β = 传感器尺寸 ÷ 视野` | 取双向较小值，保证视野全覆盖 |
| 镜头焦距 | `f = WD × β ÷ (1+β)` | β 很小时近似 `f ≈ WD × β` |
| 反算工作距离 | `WD = f × (1+β) ÷ β` | 选定标准焦距后校核 |
| 镜头解像力 | `≥ 1000 ÷ (2 × 像素尺寸μm)` lp/mm | 奈奎斯特极限 |
| 景深 | `DOF ≈ 2 × δ × F数 × (1+β) ÷ β²` | 与倍率平方成反比 |
| 高度差误差 | `Δ ≈ (视野/2) × Δh ÷ (WD − Δh)` | 超过精度要求则需远心镜头 |

视野 200×150 mm，精度 0.1 mm，工作距离约 500 mm：

```
所需分辨率：4000 × 3000 px（≈12 MP）
推荐相机：Sony IMX253（4096×3000，3.45μm，1.1″）
推荐镜头：35 mm 定焦，≥16MP 等级，解像力 ≥145 lp/mm
工作距离：≈542 mm　　景深：±44.9 mm（F/4）
```
